# Parry

Práctica de oído para el parry de Deadlock. Suena una teamfight y, cuando escuchas el golpe cargado, presionas parry antes de que te pegue. Si te pega, pierdes.

**Jugar:** https://davidvalenciadiosa-ux.github.io/parry-deadlock/

- Usa audífonos: los sonidos vienen de distintos lados.
- El parry dura 0,75 s y tiene 4,5 s de enfriamiento, igual que en el juego. No lo spamees.
- Tres modos: Tranqui, Pelea y TF 6v6 (con fintas).
- En Ajustes puedes cambiar la tecla (también los botones del mouse), los volúmenes y el tiempo de carga del golpe.

Los sonidos son de Deadlock (Valve) y se usan sin fines comerciales para practicar. Este proyecto no está afiliado a Valve.
